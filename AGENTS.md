# Working in this repository

Read README.md and CONTRIBUTING.md before changing code. Use Node.js 24 and pnpm 10.29.3.
Run `pnpm check` for changes to source or dependencies.

This is an automated export. Accepted changes must be applied to the authoritative product
monorepo before the next export. Do not add an independent publish or production deploy workflow.
Never commit API keys, generated build output, or local environment files.
